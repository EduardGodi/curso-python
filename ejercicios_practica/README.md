## 🛠️ ¿Cómo resolver y ejecutar los ejercicios?

1. Abre cualquiera de los archivos `.py` en tu editor de código.
2. Lee las instrucciones escritas en los comentarios.
3. Escribe tu código debajo de los comentarios `# TU CÓDIGO AQUÍ`.
4. Ejecuta el archivo en tu terminal para ver si funciona:
   ```bash
   python nombre_del_archivo.py
   ```
